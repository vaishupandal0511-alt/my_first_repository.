DermaGlow AI – Your Intelligent Skincare Assistant

About the Project

DermaGlow AI is an AI-powered skincare chatbot designed to provide basic skincare guidance and personalized skincare suggestions. It helps users understand skincare ingredients, identify suitable skincare practices, and create daily skincare routines.

Features

* AI Skincare Chatbot: Answers general skincare questions.
* Ingredient Checker: Explains skincare ingredients and their benefits.
* Product Recommendation: Suggests suitable product types and ingredients.
* Daily Skincare Routine: Generates morning and evening routines.
* Skin Safety Checker: Provides general skincare precautions.
* Skincare Quiz: Helps users understand their skincare preferences.
* Save My Routine: Allows users to save their routine during the app session.

Technologies Used

* Python
* Streamlit
* Ollama
* Llama 3.2 (1B)
* Visual Studio Code
* Git and GitHub

How to Run the Project

1. Install Python.
2. Install Ollama.
3. Download the model:
    ollama pull llama3.2:1b
4. Install the required Python packages:
    pip install streamlit ollama
5. Open the project folder in VS Code.
6. Run the application:
    python -m streamlit run app.py

Project Objective

The main objective of DermaGlow AI is to make basic skincare information easier to understand through an interactive AI-powered chatbot.
